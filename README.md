## 🔬 Yantra Gyan

**Yantra Gyan** is my personal simulation and learning journey.

The goal is simple:

**Simulate • Learn • Explore • Share**

During weekends and whenever I get some free time, I plan to work on simulations and document not only the final results, but also the engineering thought process behind them.

Each project will try to include:

* 📖 Background and theory
* 🧮 Mathematical modelling
* 💻 Implementation
* 🧪 Simulation setup
* 📊 Results
* 🔍 Results & discussion
* 💡 Lessons learned
* 🚀 Possible improvements

I will use **open-source platforms wherever practical**, with the longer-term goal of moving from standalone simulations toward realistic robotic environments using **ROS 2 and Gazebo**, followed by exploration of advanced and learning-based algorithms.
